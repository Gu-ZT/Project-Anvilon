## 项目介绍

世界的本源，是一颗颗名为「砧子（Anvilon）」的基本粒子。它们依照某种秩序排列与运转，构成了我们所见的现实。

借助 **Anvilon Recompiler（砧子重编译器）**，你可以按照 **Anvilon Recompile Protocol（砧子重编译协议）**
中记录的演算步骤，对砧子进行演算与重组，从而改写现实、达成超乎常理的效果。

散落在世界各地的协议片元，记载着修改现实表象所需的具体步骤。收集、解读并重编译它们，亲手重写这个世界的规则。
